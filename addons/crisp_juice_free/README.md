# Crisp Juice Free

8 free sprite-sheet effects for casual and puzzle games (gem burst, coins, stars, confetti, impacts, sparkle) as ready scenes, with a one-line spawn helper.

Free sampler of Crisp Juice: https://anipixels.itch.io/crisp-juice
Demo scene: `res://addons/crisp_juice_free/demo/vfx_demo.tscn`
Documentation: https://github.com/Anipixels/crisp-juice-free
